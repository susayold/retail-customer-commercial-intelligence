# Retail Customer & Commercial Intelligence — Web Dashboard

This folder contains the source-backed static web dashboard published from the retail DA project.

- Live site: https://marketlens-growth-seller-intelligence.sangkenny200.chatgpt.site/?v=page1
- Entry point: index.html
- Data: data.js is a compact aggregate snapshot generated from the Drive-curated retail marts. Raw Parquet files are not included.
- Interactions: filters, chart/table drill-down, and source-backed detail drawer.

The dashboard preserves the source semantics: observed panel behaviour, observation-week indexes, and observational promotion/campaign comparisons.
