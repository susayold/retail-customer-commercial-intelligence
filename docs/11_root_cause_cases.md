# Root-cause case studies

These cases are intentionally templates until the Drive data run produces verified numbers.

## Case A — Panel spend decline

Metric tree: Panel Net Spend → Active Panel Households → Trips per Active Household → Spend per Basket.

Required evidence: period comparison, exact identity reconciliation, segment/category drilldown, sample sizes and data-quality status.

Decision language: identify the accounting driver and propose a measurable intervention. Do not infer causality from association.

## Case B — Category erosion

Metric tree: Category Spend → Buying Households → Trips per Buying Household → Spend per Category Basket.

Required evidence: category penetration, frequency, basket value, private/national mix, promotion state and cross-category attach.

## Case C — Weak campaign response

Funnel: recipient households → redeemer households → validated related-product purchase → observable repeat purchase.

Required evidence: numerator/denominator, campaign type, segment, pre-period behavior, observability flags and selection-bias caveat.

## Case D — Promotion dependency (optional)

Use only after v1 core analytics. Compare activity during none/display/mailer/display_and_mailer states with sample sizes and association wording.
